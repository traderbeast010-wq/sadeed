# سديد · Sadeed

منصّة ذكاء اصطناعيّ تُدقّق العقود مقابل **القوانين العُمانية السبعة** النافذة،
وتجيب أسئلة المحامي القانونية — بحيث يكون **كل حكم مستنداً إلى نصّ مادة حقيقية،
لا رأياً مُختلَقاً**. تعمل بالكامل **محلياً** عبر llama.cpp، بلا أي اتصال بخدمة
ذكاء اصطناعيّ خارجية.

## المزايا
- **تدقيق العقود**: تفكيك إلى بنود، وحكم على كلٍّ (مخالف/ناقص/سليم/لا مادة ذات صلة)
  مع نصّ المادة ورقمها، ودرجة قوّة للعقد.
- **المساعد القانونيّ العام**: أسئلة عن أحكام القوانين، بإجابات موثّقة بالمادة.
- **العقد المصحَّح**: صياغة بديلة لكل بند مخالف، تُقبَل بنقرة وتُنزَّل.
- **إدارة المكتب**: عملاء، أسعار وأتعاب، فواتير رسمية بترويسة المكتب، لوحة إيرادات.
- **المكتبة والبحث · طابور المراجعة · متابعة المهل · سجلّ الاستشارات**.
- **تقرير رسميّ (PDF)** بترويسة المكتب، ومصادقة محلية للمستخدمين.

## المكوّنات
- **الواجهة**: Next.js 16 (App Router) + Tailwind v4 + RTL — في `web/`.
- **الخادم**: FastAPI (`api/`) + وكيل التدقيق (`agent/`) + الاسترجاع الهجين (`rag/`).
- **النموذج**: Qwen (توليد) + bge-m3 (تضمين) عبر llama.cpp — خادم HTTP محليّ.
- **التخزين**: SQLite (`lawmind.db`).

## التشغيل المحليّ (Windows)
المتطلّبات (غير مرفوعة على Git — كبيرة): `models/` (النموذجان)، و`llamacpp/` /
`llamacpp-vulkan/` (ثنائيات llama.cpp)، و`corpus/` (مرفوع، الفهرس جاهز).

```powershell
# الخادم + النموذج + الواجهة، دفعة واحدة
.\run.ps1
# أو وضع العرض (يحرّر الذاكرة ويُحمّي النموذج)
.\run.ps1 -Demo
```
ثم افتح http://localhost:3000

### تشغيل يدويّ
```bash
# الخادم (بايثون)
python -m venv .venv && . .venv/Scripts/activate
pip install -r requirements.txt
python -m uvicorn api.main:app --port 8000
# الواجهة
cd web && npm install && npm run dev
```

## النشر (VPS + Vercel)
لجعل النظام حيّاً 24/7 بلا حاجة لجهازك: الواجهة على Vercel، والخادم مع النموذج
على VPS. الدليل الكامل خطوة بخطوة في **[deploy/DEPLOY.md](deploy/DEPLOY.md)**.

## المبدأ
- **صفر هلوسة**: النصّ يأتي من الكوربوس لا النموذج، وحارس بَعديّ يرفض أي استشهاد
  بمادة لم تُسترجَع.
- **بلا API لشركات الذكاء الاصطناعيّ**: النموذج يُنزَّل ويُشغَّل ذاتياً على
  `127.0.0.1`.
- **المحامي صاحب القرار**: أداة مساعِدة لا مُفتية.
